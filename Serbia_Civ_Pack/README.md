# Serbia Civilization Pack (Civ VI)

Adds **Serbia** with four leaders: **Josip Broz Tito**, **Draža Mihailović**, **Slobodan Milošević**, and **Stefan Dušan**.

## Install

1. Fully quit Civ 6.
2. Copy the whole `Serbia_Civ_Pack` folder into:
   `Documents\\My Games\\Sid Meier's Civilization VI (Epic)\\Mods\\`
3. **Install leader faces** (required):
   - Extract **Serbia_Leader_Portraits_READY.zip** into `Serbia_Civ_Pack\\Art\\`
   - Or double-click `tools\\INSTALL_PORTRAITS.bat` (needs Python).
4. Enable the mod in Additional Content.
5. Start a **new** game.

Details: `Art/PORTRAITS_README.md`

## Requirements
Rise and Fall + Gathering Storm.

## Leaders
| Leader | Ability | Unique Unit |
|--------|---------|-------------|
| **Tito** | IZ +2 Prod/+2 Sci; Campus +2 Prod; Communism +25% Prod & Sci | **Partizani** |
| **Draža** | +8 Faith/city; Faith purchases; **Gold = Faith output** | **Chetnik** |
| **Milošević** | +2 Culture, +10 Loyalty, less war weariness, +10 CS | **Neva-M** |
| **Dušan** | +2 Culture, +2 Loyalty | **Almanska Garda** |

## Debug
F8 / F12 panel. Disable with `SERBIA_ENABLE_DEBUG = false` in `UI/SerbiaDebug.lua` and `Scripts/SerbiaCheats.lua`.
