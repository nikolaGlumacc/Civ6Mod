# WW2 Overhaul v1.1 – Europe focus

## How to play on the Europe map

1. Enable Rise and Fall + Gathering Storm  
2. Enable **Serbia Civilization Pack** (for your Serbian leaders)  
3. Enable **WW2 Overhaul**  
4. Create Game → **Map: Europe** (or any True Start Europe / YnAMP Europe map)  
5. Ruleset: **Expansion 2**  
6. Advanced Setup → pick **Army Doctrine** (Light / Medium / Heavy)  
7. Add these civilizations manually (recommended):

| Country | Civ to pick |
|---------|-------------|
| **Germany** | Germany |
| **Britain** | England |
| **France** | France |
| **Spain** | Spain |
| **Russia / USSR** | Russia |
| **Poland** | Poland (if you have it) |
| **Hungary** | Hungary (if you have it) |
| **Yugoslavia** | Yugoslavia (from this mod) **or** Serbia from your Serbia pack |
| Italy | Rome / Italy stand-in |

Put them in true-ish positions on the Europe map (or use a True Start Europe map if you have one).

---

## Join other countries (Yugoslavia → Germany / USSR etc.)

New Wildcard policies:

- **Join Germany** / **Axis Alignment**  
  +6 Combat Strength, +15% unit Production  
  Use when Yugoslavia (or another minor) sides with Germany.

- **Join USSR** / **Comintern**  
  +10% Science, +15% unit Production, +5 Combat Strength  
  Use when siding with the Soviet Union.

This is the practical “join a major power” system in Civ 6:
- You keep playing your civ but get the bonuses of that sphere.
- Full city-transfer annex (you literally become part of Germany/USSR) is possible by gifting cities in diplomacy; automatic full annex is kept limited so it does not break the game.

## Everything else still works

- Domination only  
- National Stubbornness (lose cities → big temporary boost)  
- Supply Depots (city/regional)  
- Oil maintenance  
- Stronger industry  
- 1936-style start  
- Compatible with Serbia pack

**Yugoslavia is priority.** Use either the sample Yugoslavia in this mod or your Serbia leaders on the Europe map, then use Join Germany / Join USSR when you want to align.
